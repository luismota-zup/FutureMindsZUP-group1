as suas regras.

Escolha o CSV ou cole as reclamações em texto, defina o formato de saída e edite os agentes em .claude/agents. Nada é enviado ao modelo até você confirmar o número de chamadas.

PASSO 1

Suas reclamações

Formato da entrada

Cada reclamação é um bloco separado por linha em branco; sem linhas em branco, cada linha é uma reclamação. O prefixo ID: é opcional; sem ele, o id é o número da reclamação. No texto livre só existem as colunas id e texto_reclamacao.

Para um teste barato, processe só 2 ou 3 linhas primeiro. O arquivo fica apenas neste navegador e no servidor local, e vai ao provedor só quando você executa.

PASSO 2

Regras e formato de saída

Campos do resultado

Cada campo vira uma coluna. Com valores permitidos, qualquer resposta fora da lista é recusada e a linha aparece como falha. Sem valores, o campo é texto livre. A coluna id sempre vem primeiro.

Essas colunas vão direto da entrada para a saída, sem passar pelo modelo (só pela máscara de dados sensíveis).

CONHECIMENTO DOS AGENTES

Política interna (RAG)

O documento é dividido em seções e indexado com embeddings. Para cada reclamação, os agentes com politica: no cabeçalho recebem só os trechos relevantes (similaridade com o texto, canal, produto e urgência) e citam a seção usada.

Carregando…

Aceita .pdf, .md ou .txt de até 3 MB. A troca vale para os próximos processamentos até reiniciar o servidor; um lote em andamento termina com a política com que começou. Para fixar outro arquivo, use --politica ao iniciar.
